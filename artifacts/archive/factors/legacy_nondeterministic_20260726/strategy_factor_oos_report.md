# 因子工厂 Walk-Forward OOS + Deflated Sharpe 验证报告

> 生成：`run_factor_oos.py`（2026-07-22）
> 目的：把 P5/P6 因子工厂的"样本内 Top 因子"做样本外验证，并用 Deflated Sharpe Ratio（Bailey–De Prado）校正多重检验，回答一句关键问题——**随机 DSL 因子搜索到底有没有真 alpha？**

## 1. 方法

- **数据切分（walk-forward）**
  - 训练段：`2025-01-01 ~ 2025-12-31`（393 只有效，共 400 抽样）
  - 测试段：`2026-01-01 ~ 2026-06-24`（398 只有效）
  - 训练/测试共有 **393 只**，避免前视与幸存者偏差。
- **公式集合**：与 `run_factor_search.py` 同 seed（20260622），共 **1205** 个 RPN 公式（含 5 个种子式 + 1200 随机式），训练/测试各评一次。
- **评估口径**：横截面 IC、ICIR、Top-decile 多头 Sharpe（`cross_sectional_score`）。
- **选择**：训练段按 ICIR 选 Top-20。
- **DSR 校正**：用 **全部 248 个随机公式在测试段的 Sharpe** 作为 null 分布，取最大者 `null_max` 作 benchmark，对最佳 OOS 因子算
  `DSR = P(SR_observed > SR_null_max)`（= `1 - dsr_pvalue`，高斯近似，T = 测试段交易日数 − 1）。

## 2. 核心结果

### 2.1 测试段 null 分布（248 个随机公式）—— 这是灵魂

| 指标 | 值 |
|---|---|
| 随机公式数 | 248 |
| 平均 Sharpe | +0.146 |
| 标准差 | **2.295** |
| **最大 Sharpe（最幸运的随机公式）** | **+4.953** |
| 正比例 | 42.3% |

> 仅仅 248 次随机试验，仅凭**多重检验运气**，测试段就能撞出 Sharpe ≈ +4.95 的"最佳因子"。
> 这定义了"显著性"的及格线：任何精选因子若想声称有 alpha，必须**稳定超过 +4.95 这个随机天花板**。

### 2.2 训练段选出的"最佳" OOS 因子

| 因子 | 公式 | 训练 ICIR | 测试 ICIR | 测试 Sharpe | OOS 分位(在 null 中) |
|---|---|---|---|---|---|
| **rand_522** | `RSI14 ABS ABS TURN MUL NEG RSI14 ADD MOM20 ADD` | +3.64 | +8.89 | **+4.70** | 0.98 |
| rand_420 | `MOM20 VOL_RATIO MUL DECAY MAX3 MA20_DEV MUL AMP MOM20 JUMP SUB DIV` | +3.92 | −0.98 | +3.29 | 0.85 |
| rand_419 | `RSI14 RET NEG SUB RSI14 MA20_DEV ABS SIGN SUB ABS ADD` | +3.77 | +7.83 | +2.56 | 0.82 |
| rand_799 | `VOL_RATIO MOM20 DIV MOM5 DIV JUMP RET ADD AMP DIV` | +8.18 | +11.98 | +2.25 | 0.79 |
| rand_845 | `AMP TURN NEG ADD MA60_DEV TURN JUMP ADD RSI14 MOM20 ADD MUL ADD` | +4.72 | +6.03 | +0.83 | 0.67 |

> **注意：最佳训练因子 `rand_522` 测试段 Sharpe +4.70，仍低于随机天花板 +4.953。**

### 2.3 Deflated Sharpe 判定（决定成败）

| 指标 | 值 | 读法 |
|---|---|---|
| 最佳 OOS 因子 | rand_522 | — |
| 最佳 OOS Sharpe | +4.704 | — |
| PSR `P(SR>0)` | **≈1.0**（p≤0 = 0.0） | 因子确实盈利（废话，Sharpe 4.7 自然>0） |
| **DSR `P(SR > null_max)`** | **≈0.29**（p≤null_max = 0.7135） | **只有 ~29% 概率真正超过最幸运的随机公式 → 不显著** |

> **结论：经 Deflated Sharpe 校正后，训练段精选因子与"最幸运随机公式"在统计上不可区分。因子工厂没有挖掘出可证伪的 alpha。**

### 2.4 训练→测试的瓦解（过拟合铁证）

Top-20 by 训练 ICIR 中，**大量因子测试段 Sharpe 转负 / ICIR 严重衰减**：

| 因子 | 训练 ICIR | 测试 Sharpe | ICIR 衰减 |
|---|---|---|---|
| rand_779 | +4.17 | **−0.59** | −9.32 |
| rand_952 | +4.21 | **−0.83** | −6.65 |
| rand_132 | +4.11 | **−0.59** | −6.13 |
| rand_642 | +4.44 | +0.06 | −5.87 |
| rand_1151 | +5.55 | **−0.87** | −5.30 |
| rand_52 | +6.61 | **−0.38** | +5.09 |

> 训练 ICIR 在这个样本量下**完全无法预测测试表现**——它测量的是噪声，不是信号。

## 3. 结论

1. **随机 DSL 因子搜索在当前样本量下统计上徒劳**：393 只 × 63 个测试日 × 1205 个公式，随机运气即可产生 Sharpe ≈ +4.95 的"冠军"，而精选最佳仅 +4.70，且经 DSR 校正后不显著。
2. **DSR 校正做对了它的工作**：它正确地"戳破"了 P5/P6 看到的样本内幻象（P6 里 `rand_1002/rand_107` 样本内 Sharpe +2.9/+2.4，接入引擎后 −97%/−31% 崩盘，本质也正是多重检验幸存者偏差）。
3. **DSL 框架本身有价值，该保留的是"表示层"而非"随机搜索"**：StackVM + RPN 能精准表达已知策略（MOM20/MA20_DEV），评估纪律（IC + OOS + DSR）也成立。但**随机生成器 = 钓鱼（data snooping）的源头**，应废掉。

## 4. 下一步（路线修正）

| 方向 | 说明 | 为何现在更优先 |
|---|---|---|
| **C. 语义驱动因子生成（吸 AlphaGPT 精华的升级版）** | 由你用自然语言描述行情观点 → 我翻译为 DSL 公式 → 同一套 OOS+DSR 验证。候选数极少（个位数），DSR 才能显著。 | **最高优先**：随机搜索已被证伪，语义驱动把"钓鱼"变"假设检验"。 |
| **D. 因子 ensemble** | 把多个 OOS 正向因子等权合成 score。但单因子若都落在噪声里，ensemble 也救不回——需先有真 IC 因子。 | 排在 C 之后。 |
| **更大样本** | 拉长历史 / 更多 regime / 更大股票池，抬升 DSR 拒绝域。 | 数据成本最高，先做 C。 |
| **B. OOS 幸存因子引擎级回测** | 对经 DSR 确认显著的因子接回真实引擎。当前无显著因子，暂搁置。 | 等 C 产出显著因子再做。 |
