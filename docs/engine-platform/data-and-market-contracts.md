# 数据与市场接入

数据来源继续通过 TSP 的数据源配置及插件能力接入；独立数据引擎的同步请求、历史口径和旧库导入见 [Tivelo Data](../../packages/tivelo-data/README.md)。现有股票回测按实际行情日期推进。

## 为研究任务准备输入

- 普通 A 股工作台按行情日期回放。调度计划选择「交易日」触发时，使用本机已经安装且覆盖所选日期的日历预设。[触发计划](workbench-research-jobs.md#按交易日派发)
- 为严格历史研究保留原价、因子、标的及时间约定。单次除权事件、累计因子和最终复权价格应在各自字段中明确表达。
- 当供应商只返回最新数据时，记录实际采集或发布日期。可知时间和历史修订要由有追溯记录的数据源提供。用同一标的和日期核对两条数据路由。
- 检查已发布快照的范围和引用，再将快照交给独立引擎。原有工作台插件及 YAML 使用各自的现行契约。[双端数据源示例](../../examples/dual-host-data-source/README.md)

## 复核旧沪深股票因子归档

导入旧除权事件时，如遇数值精度错误，可根据错误记录中的证券、除权日期、字段、源文件摘要及行号，核对本机 `adj_factor/all.parquet` 与供应商原始数据。修改源数据后应重新生成采集计划，再比较导入结果。原有文件中的缺失值或历史修订无法由引擎自动补全。
