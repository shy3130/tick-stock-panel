# Dow Monitor Mobile Layout Precedence

Decision ID: `DEC-20260731-DOW-MONITOR-MOBILE-LAYOUT-001`

Approved by the user on 2026-07-31.

The existing complete-list requirement remains authoritative for viewports at
or above 768 CSS pixels. For viewports below 768 CSS pixels,
`SPEC-DOW-MONITOR-MOBILE-VERSION-REFRESH-001` takes precedence only for which
fields are visible in the list. It does not remove any indicator capability:
all indicators remain available in the existing detail view.
