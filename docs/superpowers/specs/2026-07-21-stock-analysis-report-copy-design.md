# 个股分析报告复制按钮设计

## 目标

让用户在个股 AI 报告生成完成或查看历史报告时，能够从标题栏右上角清晰地复制完整报告，并粘贴到微信、飞书、Obsidian或其他应用。

## 交互设计

- 报告有内容且不再生成时，在标题栏右上角显示带复制图标和文字的“复制报告”按钮。
- 报告生成中不显示复制按钮，避免复制到不完整内容。
- 点击成功后，按钮临时显示“已复制”和成功图标，2秒后恢复。
- 复制失败时，按钮临时显示“复制失败”，并保持页面可继续操作。
- 按钮使用紧凑文字样式，在手机端不挤压股票名称、代码和关闭按钮。

## 复制内容与兼容策略

- 复制报告的原始 Markdown 文本，不复制网页样式或HTML。
- 优先调用 `navigator.clipboard.writeText`。
- 当剪贴板API不存在或调用失败时，使用临时只读文本域、选中文本并调用浏览器复制命令作为降级方案。
- 临时节点在复制后立即移除，不改变页面滚动位置和报告内容。

## 组件边界

- 复制逻辑提取为独立工具函数，负责现代剪贴板和兼容降级。
- `StockAnalysisDialog` 只负责按钮显示、调用复制函数及成功/失败状态。
- 不修改报告生成、保存、历史报告或后端接口。

## 测试与验收

- 前端行为测试验证完成报告显示“复制报告”，生成中不显示。
- 测试验证现代剪贴板成功时写入完整 Markdown，并显示“已复制”。
- 测试验证现代剪贴板失败时启用兼容降级。
- 测试验证两种复制方式都失败时显示“复制失败”。
- TypeScript/Vite生产构建必须通过。
- 生产页面在桌面端和手机宽度下均能看到文字按钮。

## 非目标

- 不增加系统分享按钮。
- 不改变报告内容格式。
- 不为历史报告重新生成内容。
