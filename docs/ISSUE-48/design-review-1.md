# Issue #48 设计评审一

## 评审发现

1. 若把当前红柱段的最终峰值写入历史信号，会引入未来函数；改为截至信号日的 running peak。
2. “新高”必须唯一化，冻结为当日 high 严格超过前 60 根 high 的最大值。
3. S8 的阴线使用严格 `close < open`，doji 不算阴线且打断连续性。
4. S9 的可用时点是当日开盘，而不是收盘；证据保留 `available_at_session=open` 与 `existing_position_required=true`。
5. 卖飞与规避不能合并成一个方向判断；分别报告上涨比例/上涨均值与下跌事件最大回撤均值。

## 结论

通过。检测只使用日线前缀；分钟信号不降级为日线近似；研究层按信号独立聚合。
