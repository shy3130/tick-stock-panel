# 实施计划 v1

日期：2026-08-27

## 目标

新增单阳不破研究服务和 research API，记录 raw 价格行为定义，并用 focused tests
锁定阳线与后续窗口判断。

## 初版方案

1. 在 `services/` 增加纯函数模块，接收 OHLC bar 序列。
2. 判断阳线、实体与影线，检查后续若干根 K 线是否跌破阳线低点。
3. 在 `api/research.py` 增加 GET 入口，返回研究结果。
4. 增加单元/API 测试，覆盖正常、不破与破低场景。
5. 若没有数据则返回 unavailable。

## 待决口径

v1 尚未固定实体阈值、等于低点是否算破、尾部不完整窗口、T+1 以及 IS/OOS
边界；也未明确 reader 的 generation pin 和服务在能力补齐后的开放条件。
这些问题必须在 v1 评审后解决，不能带入生产实现。
