# v0.4.2 版本说明

本页记录 v0.4.2 的变更及升级步骤。请从对应版本下载适用的安装包。[GitHub Releases](https://github.com/shy3130/tick-stock-panel/releases)

## 主要变化

- **分钟 K 同步与数据路径兼容。** 新增分钟 K 按日重拉与按日期范围拉取能力，便于精准补齐和修正历史分钟数据；修复包含特殊字符或大小写差异路径下的行情数据读取与 DuckDB 视图兼容性。[功能手册](./features.md)
- **图表指标与交互体验。** 新建及内置图表指标切换至自有表达式引擎，修复界面缩放下图表十字准星偏移；优化策略列表按实时行情事件刷新、AI 分析报告排版与部分页面交互细节。[个股详情与图表指标](./custom-chart-indicators.md)
- **估值口径修正。** 工作台估值类因子（PB、VWAP 偏离度、流通市值对数）统一基于交易所原始收盘价计算，并复用独立评分口径。
- **安全边界加固。** 修复反代场景下 `X-Forwarded-For` 解析与内网/回环 IP 校验，防止伪造头绕过内网门禁和登录限流；收紧默认 CORS 为仅同源（支持通过 `CORS_ALLOW_ORIGINS` 显式配置白名单），拦截非 Bearer 跨站写请求；为页面插件管理、配置备份、源码扩展删除、插件安装、Token 管理、策略代码保存/删除与仓位策略等高危管理接口统一接入 `require_management` 门禁，并为修改密码补齐失败限流检查。[访问密码](./deploy-password.md)

## 升级与回滚

1. **升级前。** 在「设置 → 导入与备份」导出配置，停止旧实例后备份实际数据目录。保留旧安装包或镜像版本及原启动参数，以便回滚。Compose 和 Docker 用户先核对容器的 `DATA_DIR` 与宿主机挂载。[数据目录核对](./deployment.md#docker-升级前核对数据目录)
2. **升级。** 桌面版沿用原安装位置；Docker 重建时使用原数据挂载，源码部署按锁文件同步依赖。Docker 用户可固定到 `v0.4.2` 镜像标签，也可从对应源码构建。[桌面升级](./deployment.md#桌面版覆盖升级与旧配置恢复) · [部署步骤](./deployment.md)
3. **升级后。** 在「设置 → 关于」确认版本号为 `v0.4.2`。若此前在**局域网未设密码**状态下从其他设备访问备份导出、插件安装或策略代码保存，升级后请先设置访问密码再登录。如有独立外部前端跨域直连需求，可通过环境变量 `CORS_ALLOW_ORIGINS` 显式配置来源白名单。
4. **回滚。** 先停新版并保留本次运行的数据。用旧程序或旧镜像读取升级前备份的副本，核对设置、行情和策略可用后再恢复运行。
