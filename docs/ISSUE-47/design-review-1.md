# Issue #47 设计评审一：时序与数据

## 结论

通过，前提是所有 detector 保持前缀闭合。

## 评审修正

1. F2 不能把三日未回补的结论写回缺口日；确认日固定为缺口日后的第三个完整交易日。
2. F1 优先使用 published `ztj`；仅在缺失时使用同日 PIT `is_st/regime`，其中 ST 必须覆盖为 5%。
3. F3 基准缺失不得按零收益处理。
4. F4 每个堆量日都要高于冻结的前置基线，不能只比较窗口平均值。
5. future-surge 标签只存在于聚合器，detector 不得读取。

## 威胁模型

- 当前名称/制度反推历史；
- F2 回填导致未来函数；
- 基准缺失造成选择性删样；
- 用上涨样本内出现率替代预测 lift；
- 四项打包平均掩盖单项失效。
