# Documentation

当前项目是无自定义前端的 Python/FastAPI 量化研究与回测后端。

- `configuration.md`：环境变量和数据源配置。
- `deployment.md` / `deploy-password.md`：API 与 Docker 部署。
- `strategy.md`：当前后端策略生命周期和开发规范。
- `custom-data-source.md`：自定义数据源。
- `plugin-development.md`：数据源插件。
- `examples/`：可运行示例。
- `archive/legacy-panel/`：已下线页面工作流，仅供追溯。
- `archive/ui-screenshots/`：已下线 UI 截图。

以页面点击、选股页或设置页为主体的旧工作流必须放在 `archive/`，不能与当前入口混放。
