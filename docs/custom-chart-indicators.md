# 自定义图表指标

当前个股详情统一使用自定义指标布局。宽屏上日 K 和单日分时横向对齐，时间轴位于价格主图下方，指标副图按方案排在时间轴下面。尚未保存过指标方案的工作区打开个股详情时，日 K 默认显示 MA 和成交量。MACD 等可在指标列表按需添加。已有的日 K 和分时方案继续按原样读取，包括已隐藏的指标和已清空的方案。

## 使用

在个股详情右上角点击齿轮，打开「默认配置」。日 K 首屏默认显示最近 60 根，可修改后保存。半年、一年和自选日期控制加载区间。这项配置随配置备份的「偏好设置」导出和恢复。

齿轮菜单中的「自定义信息条」可编辑股价下方的信息。可勾选内置指标或已接入的扩展数据字段，在右侧拖动排序、隐藏字段或设为单独一行。点击「保存」后生效，「设为默认方案」也随这次保存生效。升级后打开工作台时，如果服务端尚无信息条配置，当前浏览器的旧布局和旧默认方案会自动迁移。布局和默认方案都随配置备份的「偏好设置」导出和恢复。

1. 打开个股详情，在日 K 或分时图表中点击自定义指标图标。在「指标列表」的「内置指标」中可添加 MA、MACD、成交量、RSI、KDJ 和 BOLL。窄屏先点击「指标列表」展开。添加后点击「保存方案」即可显示。
2. 需要自定义公式时可新建空白指标，粘贴源码并命名。已添加的内置指标也可编辑、复制和导出，在另一视图勾选同一个指标即可复用。
3. 源码中的 `N` 等外部周期变量需在「参数」页签添加同名参数，也可在源码里用 `N:=20;` 定义常量。
4. 在「显示」页签选择主图或副图、单位、小数位；分时可选择每天重置计算。
5. 点击「解析并预览」。有行情时显示曲线、绘图及末值。日 K 视图无行情时仍可解析并保存。修改源码或参数后会清除旧预览。
6. 勾选列表中的指标加入当前日 K／分时的外层按钮栏。保存后点击外层按钮切换图上显隐。加入按钮栏与图上显隐分别保存。加入内置指标时默认显示，其他指标可在按钮栏手动显示。
7. 拖动已勾选指标左侧的手柄调整顺序，也可使用右侧上移／下移箭头，再点击「保存方案」。自定义指标按钮和独立副图按此顺序排列，自定义成交量也可移动。主图叠加始终留在价格图。日 K 与分时的顺序分别保存，未勾选指标列在列表末尾。

编辑器桌面布局为左侧指标列表、中间编辑区、右侧预览与语法参考。公式、参数和显示设置通过页签切换，切换时保留草稿；旧表达式的各条输出独立展开、收起，切换输出、页签或指标后保留本次编辑的展开状态。每条输出用独立标题和边框区分变量、公式及样式设置。源码编辑区显示行号，解析错误可定位回源码。预览区可直接生成或刷新图表，并提供常用参数的本图取值快捷调整；变量名称、默认值和范围在「参数」页签管理。

窄屏下，指标列表单独打开，选择后返回编辑；预览使用独立页签，解析成功后自动切到预览。Ctrl / Command + Enter 解析预览，Ctrl / Command + S 保存方案。导入、导出放在右上角更多操作中；删除指标需先确认，保存方案后才生效。已有表达式指标继续保留原计算口径，不自动转写源码。

编辑器「语法与示例」中提供以下双均线示例。新建指标仍为空白，可自行编写或复制示例。选择「主图叠加」后，短均线上穿长均线时会在对应最低价位置绘制向上箭头：

```text
{ 双均线与上穿标记 }
短均线:MA(CLOSE,5),COLORRED;
长均线:MA(CLOSE,20),COLORBLUE;
DRAWICON(CROSS(短均线,长均线),LOW,1);
```

```text
{副图 MACD；参数也可在参数区定义}
DIF:EMA(CLOSE,12)-EMA(CLOSE,26);
DEA:EMA(DIF,9);
MACD:(DIF-DEA)*2,COLORSTICK;
```

## 公式语法与函数

源码使用安全词法转换和 AST 白名单校验，代码不会交给 Python `eval`、`exec` 或浏览器脚本执行。未知函数、属性、变量、未来函数以及静态可判断的非法周期、绘图参数在解析／保存前报错并带语句起始行号；依赖实际行情才能判定的问题在计算时带行号报错。出错时保留草稿，保存和导入不会部分写入。

| 类别 | 已支持 |
| --- | --- |
| 语法 | 中文和英文变量、大小写不敏感、`:=` 中间变量、`:` 数值输出、匿名输出、`;` 分句、`{...}` 注释、字符串、四则运算、取模、`= <> > >= < <=`、`AND OR NOT`、`&& || !` |
| 行情 | `C/CLOSE`、`O/OPEN`、`H/HIGH`、`L/LOW`、`V/VOL/VOLUME`、`AMO/AMOUNT`，以及现有规范字段 `TURNOVER_RATE`、`PREV_CLOSE`、`RAW_CLOSE`；缺失依赖明确报错 |
| 均线 | `MA EMA EXPMA EXPMEMA SMA MEMA DMA WMA` |
| 窗口统计 | `SUM HHV LLV HHVBARS LLVBARS STD STDP VAR VARP AVEDEV DEVSQ` |
| 引用、条件、事件 | `REF IF IFF IFN COUNT EVERY EXIST LAST CROSS LONGCROSS BARSLAST BARSSINCE BARSLASTCOUNT BARSCOUNT FILTER VALUEWHEN BETWEEN RANGE` |
| 数学和文本 | `ABS MAX MIN REVERSE SGN SIGN SQRT POW POWER EXP LN LOG LOG10 INTPART INT FLOOR CEILING ROUND MOD SLOPE FORCAST RGB STRCAT CON2STR VAR2STR` |
| 常量与时间 | `DRAWNULL TRUE FALSE CURRBARSCOUNT TOTALBARSCOUNT ISLASTBAR DATE TIME TIME2 YEAR MONTH DAY WEEKDAY PERIOD`；无参数 `BARSCOUNT` 为当前历史序号 |
| 数值绘图样式 | 具名 `COLOR` 和六位十六进制 BGR 颜色、`LINETHICK1..9`、`NODRAW`、`COLORSTICK VOLSTICK STICK LINESTICK DOTLINE POINTDOT CIRCLEDOT CROSSDOT DRAWABOVE`；`NODRAW` 数值输出保留读数，`DRAWABOVE` 将文字或图标置于指定价格上方，文字中的 `&` 换行 |
| 绘图语句 | `STICKLINE`（EMPTY 为 -1/0/1，宽度 0～20）、`DRAWTEXT DRAWNUMBER DRAWICON`（图标 1、2）、`DRAWBAND DRAWKLINE DRAWTEXT_FIX DRAWNUMBER_FIX` |

绘图与曲线共用图表的时间和价格坐标，随缩放、平移及窗口大小变化重新绘制。图形端点参与自动价格范围。

以下能力尚未实现，解析时会明确提示：

- 未来函数，如 `REFX BACKSET ZIG PEAK TROUGH DRAWLINE`。
- `FINANCE DYNAINFO CAPITAL COST WINNER`、指数引用、跨品种／跨周期公式以及没有接入的数据函数。
- `DRAWICON` 的其他图标、STICKLINE 特殊双轴柱 EMPTY=2/3、绘图语句的 NODRAW 文字栏，以及其他未列绘图语句和扩展属性。
- `.tn6/.tni` 原生、加密指标文件的解析。当前入口接受明文源码和本项目 JSON 指标包。

### 让 AI 编写或迁移指标

提供图表周期、目标输出、参数及至少一段可对照的 OHLCV 样本，并让 AI 只使用本页列出的函数、绘图语句与单位。先在指标编辑器「解析并预览」核对曲线和末值，再保存方案。分发定义用 `tick-chart-indicators` v1 JSON。整套按钮栏和参数使用偏好设置备份迁移。

## 数值约定和验证

公式由本项目的解析器和计算器执行。函数定义和数值约定如下；同名指标可以采用不同的周期、平滑算法和初始值，实际计算以源码为准。

- `EMA/EXPMA` 从首个有效值初始化，权重为 `2/(N+1)`；`SMA` 权重为 `M/N`，`MEMA` 为 `1/N`；`EXPMEMA` 达到 N 个有效值后才输出。
- `STD/VAR` 为样本标准差／方差（ddof=1）；`STDP/VARP` 为总体值（ddof=0）。固定窗口使用稳定滚动方差，累计方差使用 Welford 算法。
- 源码窗口从可用历史开始，早期不足 N 根时按已知有效值计算；样本标准差至少需要两个有效值。支持的累计窗口 `N=0` 从已加载历史起点计算。`REF` 越过历史起点、零分母、非法数学结果输出空值，图上不补零。
- 中文字符串可由中间变量和 `STRCAT/CON2STR` 组合。`NODRAW` 数值不画线，但仍显示读数；`:=` 中间变量不输出读数。
- 旧表达式默认 `syntax=expression`，继续使用既有 DSL 的窗口、预热和递推语义，不因新增源码模式改变结果。

`backend/tests/test_tdx_chart_formulas.py` 用固定行情和独立逐点算法对照 MACD、KDJ、RSI、普通 BOLL，以及动态窗口、标准差、回归、事件、空值和未来数据改写不影响前值。数值容差通常为 1e-10（MACD 为 1e-12）；大基数方差容差为 1e-7。此验证属于独立算法参考，**尚未进行外部客户端实测值对照**。复权方式、成交量单位、行情起点和递推初始值一致，才具备跨客户端比较条件。

## 数据、性能和边界

价格沿用当前图表口径，成交量单位为手、成交额为元。分时按原始分钟计算，保留 11:30 和 13:00 原始点，午休折叠发生在绘图阶段。启用日内重置后，每个交易日独立计算。

指标计算从当前图表和 TSP 行情仓库获取可见 K 线与预热历史。缓存使用公式、参数和完整行情内容，尾部及较早行情修正都会更新结果。TSP 在图上存在可见指标时发起批量计算。

边界为每库 48 个定义，每视图 10 个按钮，每定义 8 个参数；源码最多 40,000 字符、80 条语句、32 条数值输出、单条表达式 600 词元／24 层嵌套，总 AST 4,000 节点。周期和历史预热最多 4,096 根，单次最多 12,000 根可见行情；每定义绘图点最多 60,000，重型窗口运算量有上限。递推、累计和事件函数受已加载历史起点影响，预热不足会返回提示；不承诺无限历史结果。绘图点会裁去预热区间，并纳入缓存容量计算。

公式结果用于图表查看。若需要在回测中使用同类数值，应接入具有历史时点约束的数值因子，固定定义版本、参数、数据快照和价格口径。例如 `ISLASTBAR` 会在追加新 K 线后改变此前的结果。

## 成交量量比

分时走势中的内置成交量只显示量柱和当前成交量读数。收盘价高于上一分钟画红柱，持平画灰柱，低于上一分钟画绿柱。当天第一根以昨收为参考，缺少参考价时画灰柱。日 K 的成交量均线和量比可按原设置使用。

日 K 成交量指标的「量比 · 本图设置」控制对比周期（1～20 个交易日）、柱顶倍数标注和悬停读数。量比为当日成交量除以前 N 个交易日均量，不含当日；标注锚定实际成交量输出柱。源码用 `VOLSTICK` 标记成交量输出。设置保存在该日 K 指标的视图成员上，不修改分时和指标公式。

首次遇到尚无量比设置的自定义成交量时，会复制浏览器记住的量比开关和周期。此后可在该指标的设置中独立调整。迁移保存失败时提示并允许重试，编辑器仍可使用。

## 导入、导出和备份

- 更多操作可导出当前／全部已保存指标。独立 JSON 包上限为 8 MiB，完整源码库导出后可再次导入。格式为 `format: tick-chart-indicators`、`version: 1`，包含源码或旧表达式及参数定义，不携带本机按钮栏方案。
- 在「设置 → 导入与备份」中选择 JSON 指标包，预览新增、复用或同 ID 冲突。确认替换后应用对应定义。其他本机指标、按钮顺序、显隐及本图参数随现有配置保留。替换的定义须兼容已有视图参数。
- 配置备份勾选「偏好设置」包含整个 `chart_indicators`、源码、两套按钮栏方案、显隐、参数和量比设置。恢复前校验语法、版本、重复 ID、引用及周期。包内存在该键时整体替换指标库，旧备份缺少该键则保留本机指标库；其他偏好按原有顶层合并规则处理。
- 保存、导出和导入使用 revision 防止并发覆盖，失败保留草稿／原配置，不自动覆盖其他窗口修改。`version: 1` 和历史 `presets_version` 仍可读取；缺少 `syntax` 时按旧表达式解析，缺少 `visible` 时按显示处理。
