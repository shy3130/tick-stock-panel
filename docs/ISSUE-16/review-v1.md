# Issue #16 计划 v1 评审

## 结论

**否决（不可合并）**。

## 主要问题

1. **前视风险致命**：全历史向量化重算没有 as-of 边界，无法证明市场日 D 只消费 D 及以前的输入。
2. **PIT/generation 只是装饰**：把当前元数据贴到每行不等于引用读取时刻的冻结快照；`raw` 的来源、延迟和完整性没有定义。
3. **T+1 责任错位**：可用时点属于服务契约，不能推给调用方自行推迟；必须由服务端表达 `available_from`。
4. **OOS 缺失**：没有 IS/OOS 切分与分层报告，阶段统计的泛化性无法审计。
5. **共享管线侵入**：为单一研究需求修改现有指标管线，会让 12/26/9 与 10/20/7 的列语义并存并扩大下游影响面。
6. **能力缺口未门禁**：PIT 读取器与逐日状态机未就绪时，不应返回看似有效的阶段序列。

## v2 必须补齐

- 固定参数与状态机的可复算定义；
- `raw`、`pit`、`generation` 的字段语义和来源；
- 服务端 T+1 字段；
- OOS 协议和禁止合并 IS/OOS 的规则；
- 能力缺失时的 fail-closed 响应；
- 中性研究措辞，不输出操作建议。
