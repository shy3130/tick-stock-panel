# Issue #16 计划 v2 评审

## 结论

**批准（带约束）**。

## 通过项

- 固定 MACD(10,20,7) 解决参数漂移；
- 逐日状态机、PIT/generation/raw、T+1、OOS 均有明确契约位置；
- 200 + `status="unavailable"` 与仓内能力声明惯例一致；
- 服务层无 I/O，避免在读取器缺失时静默回退；
- 不侵入既有指标管线和存储路径。

## 合并前约束

1. `state_machine_not_implemented` 与 `oos_not_implemented` 必须始终存在，即使行情能力未来齐备也不能放行。
2. 当前 PIT 读取能力单独标注为缺失，不得用当前视图代替。
3. 载荷不能包含虚构的 `rows`、`series` 或阶段数值。
4. 参数只读固定值，不能由请求覆盖。
5. 新增内容保持中性研究措辞，不出现保留标识或操作性词汇。
6. 定向测试、编译和 diff 检查结果写入 `verification.md`。
