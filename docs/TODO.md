- [x] **引入“N 字金凤凰”首板缩量回调后二次启动形态因子**

  > 收口证据：`docs/ISSUE-8/oos-verdict.json` 固化 canonical+markets 双 generation 的 200 标的 coverage-extension audit；272 个首板基线仅形成 11 个事件（OOS 5 个），所有 1/5/10/20 日 horizon 均低于每臂 30 样本门槛，按预注册门禁最终 verdict=`rejected`。扩大样本不作为 pristine OOS 晋级证据；该保守驳回未进入短线池/Agent/默认策略。

  **定位**

  将该形态实现为 AI 短线候选池的**结构化证据因子**，用于生成、解释和排序研究候选；不得直接输出买入、卖出、目标价、“翻倍概率”或其他交易建议。候选池为空是合法结果，不得为凑数降低门槛。

  **待冻结的策略定义**

  ```text
  低位强势首板
  → 首板后 2～10 个交易日缩量回调
  → 最大回撤受控，且未跌破冻结的关键结构位
  → MA5/MA10 等均线结构未明显转弱
  → 再次放量突破关键位置，或出现二次涨停/回封
  ```

  具体条件必须参数化并在研究阶段冻结：

  1. **低位**：使用信号日可见的近 60/120 日价格分位、距离阶段高点幅度，不得读取未来数据。
  2. **强势首板**：定义首次涨停观察窗口；排除不可成交的一字板；记录封板质量、换手率、成交额和首板量比。
  3. **调整窗口**：首板后 2～10 个交易日；候选窗口只能通过 walk-forward 选择，不能使用全样本最优参数。
  4. **缩量回调**：比较调整期平均成交量与首板成交量、信号日前 20 日均量；缺量价数据时 fail-closed。
  5. **结构保持**：分别验证首板实体、首板高点、MA5/MA10 等支撑定义，避免事后选择最优支撑线。
  6. **二次启动**：放量突破、收盘确认、再次涨停及回封应作为独立信号变体，不混用统计口径。

  **数据与架构约束**

  - 仅走现有 `data_providers`、canonical `QueryService` 和 sealed 历史数据链路；禁止在业务层自行解析 TDX 原始 CSV、直连外部行情或引入新的旁路数据源。
  - 使用 point-in-time 信号日期、行业/市场状态与可用性口径；缺数据、catalog 异常或无法证明时点一致时必须显式 unavailable / fail-closed。
  - 复用 `services/short_pool.py` 的短线候选池契约：程序负责固定筛选与排序，Agent 只能解释结构化证据，不得修改候选、条件或顺序。
  - 不接真实交易，不写交易生命周期事实流，不绕过涨跌停、T+1、整手、费用、滑点和成交可达性约束。

  - 建立“全部合格首板”基准池，检验该形态因子的**增量**，而不是只展示命中案例。

  - 情绪状态变量扩展（北京炒家复盘清单）：涨停/跌停家数时间序列（近30日滚动）+ 连板梯队高度 +
    跌停位置分布（中位股跌停占比 -> 高位传染预警）作为分层维度候选；fm-cli 涨停板查询可直接取数。
  - 纳入涨停买不到、跌停卖不出、停复牌、滑点、手续费和分钟成交可达性；日线回测无法证明成交时必须带降级告警。
  - 严格区分样本内探索、walk-forward 样本外验证和部署后的 paper research；样本不足时不得宣称有效。
