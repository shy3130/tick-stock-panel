# Issue #49 设计复核二

因果时序冻结如下：

1. `seeking_up` 只维护截至当日可见的最低点；上涨达到反转阈值后进入高点跟踪。
2. `seeking_pullback` 只维护截至当日可见的最高点；收盘自高点回撤达到阈值后，历史高点才被确认。
3. `seeking_breakout` 持续更新回调低点；跌破 origin low 记录结构失败，收盘突破 swing high 才确认事件。
4. 数据尾部仍停留在任一未完成状态时不产出事件。
5. 事件确认发生在收盘，收益从下一市场日开盘起算；每个 horizon 缺完整 bar 时该结果为 null。

默认 fixed 8% 只是一条预注册基线，5%/10% 仅作事件数敏感性，不据结果自动挑阈值。
