# Issue #49 可行性核实

结论：可引入为只读、默认不晋级的日线研究能力，但不能把期货 1 分钟案例或既有“首板金凤凰”事件直接当作公共 N0。实现采用独立的 causal zigzag：上涨转折只有在反向幅度达到冻结阈值后确认；回调低点只有在后续收盘突破已确认 swing high 时才进入事件。末端未确认 swing 不出信号，因此不使用未来转折。

可证明输入为 pinned canonical raw OHLCV、市场日历及复合 reader 的 generation/manifest。默认反转阈值为固定 8%，同时输出 5%/10% 事件数敏感性；接口也支持 ATR multiple，但不自动寻优。日线执行从确认后下一市场日开盘开始，5/10/20 日结果扣除固定双边成本。

主要边界：每日 zigzag 不能证明分钟内路径；金凤凰仅作为回调量能交叉标签；样本不足时 verdict 必须 unavailable，不得晋级到选股或交易链路。
