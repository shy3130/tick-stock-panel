# 个股分析报告复制规范

规格 ID：`SPEC-STOCK-ANALYSIS-REPORT-COPY-001`

权威依据：产品负责人于 2026-07-21 确认，在个股分析报告标题栏提供清晰可见的复制入口，并选择兼容性复制方案。

## REQ-STOCK-ANALYSIS-REPORT-COPY-001

已完成的当前报告和历史报告在存在正文时，必须在标题栏显示带“复制报告”文字的操作按钮；生成中不得显示该按钮。按钮必须复制报告原始 Markdown 全文，不得复制渲染后的 HTML。

系统必须优先使用浏览器 Clipboard API；该 API 不可用或失败时，必须回退到临时只读文本域复制。复制成功显示“已复制”，失败显示“复制失败”，并在约 2 秒后恢复“复制报告”。按钮必须在手机宽度下保持可见、可点击且具备可访问名称。

## 验收

- 可执行测试证明现代剪贴板路径及临时文本域回退路径。
- 组件行为测试证明完成态、历史报告、生成态、成功与失败反馈。
- 前端生产构建通过，并验证部署页面包含新版复制操作。
