# 趋势监控放大图开关布局

## 权威来源

- 状态：authoritative
- 用户决定：2026-07-28 用户截图确认“趋势线”和“头肩形态”开关圆点显示异常。

## REQ-DOW-MONITOR-DETAIL-TOGGLE-LAYOUT-001

趋势监控完整 K 线弹窗中的“量比”“趋势线”和“头肩形态”开关必须使用一致的
轨道与圆点定位。圆点必须以轨道左边界为定位原点，并在开启和关闭状态下都完整
位于轨道内部，不得超出轨道、遮挡相邻文字或与其他控件重叠。

本修复只改变控件布局，不得改变三个开关的默认状态、图层显示逻辑、无障碍名称、
点击行为、图表数据或响应式换行规则。

## 验收

- 组件测试验证“趋势线”和“头肩形态”的圆点均固定在轨道左边界；
- 开启和关闭状态仍能正常切换；
- 生产页面几何检查验证两个圆点在轨道内部；
- 桌面端和窄屏下不出现横向溢出或文字重叠。
