# 道氏监控实时 K 线渲染性能

## REQ-DOW-MONITOR-REALTIME-RENDER-THROTTLE-001

道氏监控页面必须在接收实时报价、盘口和一分钟 K 线时保持可交互，并持续显示已有 K 线图。

只有当实时一分钟 K 线实际改变当前图表末端的最高价、最低价或收盘价时，才允许重建对应股票的 K 线图配置。仅报价、盘口或与当前末端完全相同的一分钟 K 线更新，不得改变图表对象引用，也不得触发 ECharts 全量 `setOption`。

验收要求：

1. 相同 K 线覆盖结果必须复用原图表及 K 线数组引用；
2. 最高价、最低价或收盘价发生变化时仍必须生成新图表数据；
3. 实时报价、盘口、昨收和当前价格展示继续实时更新；
4. 多只监控股票同时接收实时数据时，Chrome 页面能够完成加载、显示 K 线并保持可交互。

## REQ-DOW-MONITOR-REALTIME-RENDER-BATCH-001

实时客户端必须继续逐条接收并保存 WebStock 的最新报价、盘口和一分钟 K 线，但向 React
页面发布可见状态快照的频率不得超过每秒一次。同一秒内到达的多条消息必须合并为包含各股票
最新状态的一次快照，不能为每条消息复制整张股票状态表并触发全页重渲染。

连接状态、实时/回退状态和断开状态仍可立即发布，不能因为行情合并而延迟连接故障提示。

验收要求：

1. 一秒内连续到达多条有效行情时，页面订阅者最多收到一次行情快照通知；
2. 合并后的快照必须包含窗口内最后一条有效行情，不得丢失最新价格；
3. 不同股票在同一窗口内的最新状态必须同时保留；
4. `getState` 仍能读取客户端已经接收的最新内部状态；
5. 连接状态变化继续立即通知页面；
6. 两个同时打开的港股监控终端在开盘实时数据下均可完成加载并保持可交互。
