# 个股详情当日实时蜡烛规范

规格 ID：`SPEC-STOCK-DETAIL-REALTIME-CANDLE-001`

权威依据：产品负责人于 2026-07-21 确认修复个股详情页的实时开盘价、最高价、最低价、最新价和涨幅。

## REQ-STOCK-DETAIL-REALTIME-CANDLE-001

个股日线详情在展示当前交易日时，必须使用当前配置的实时行情源覆盖或追加最新蜡烛的开盘价、最高价、最低价、最新价、成交量和成交额。实时行情未提供昨收或涨幅时，必须以前一根有效日线收盘价为昨收，计算涨跌幅。

实时蜡烛的日期必须按证券所属市场时区从行情时间戳确定；美股使用 `America/New_York`，不得以服务器或北京时间日期替代美股交易日。

用户选择的历史区间结束日期早于实时行情交易日时，系统不得读取或混入实时行情。实时字段缺失或无效时必须保留已有日线字段。

## 验收

- 可执行测试以 NBIS 类美股数据验证实时 OHLC、最新价、成交量、成交额和昨收回退涨幅。
- 可执行测试验证北京时间跨日时，美股实时蜡烛仍归入纽约交易日。
- 可执行测试验证历史区间不访问实时行情源。
