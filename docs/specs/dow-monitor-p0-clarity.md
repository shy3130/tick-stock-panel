# 趋势监控 P0 指标语义优化

## 适用范围

本规范只调整 `/dow-monitor` 高密度列表及指标帮助页对既有数据的解释与展示，不改变后端分钟决策、通知、信号生成、信号失效或 WebSocket 数据采集语义。

## REQ-DOW-MONITOR-P0-SEMANTICS-001

趋势监控列表必须准确表达现有稳定指标：

1. 原“成本”必须改为“VWAP”，同时展示后端分钟决策中的日内 `vwap_price` 和 `vwap_distance_pct`；不得把它描述为用户持仓成本或 VWAP 方向。
2. 原“主买”必须改为“资金流入占比”，继续只在 `intraday_capital.quality == COMPLETE` 且分母有效时展示 `total_in / (total_in + total_out)`；不得把该值描述为逐笔主动买入成交占比。
3. 原“确认 N/2”必须明确为“周期确认 N/2”，分母固定为 15m、30m，并分别展示两个周期的已确认或待确认状态。
4. 缺失值必须显示 `--` 或“未确认”，不得以零值伪装。

## REQ-DOW-MONITOR-P0-POSITION-RISK-001

趋势监控列表必须增加以下只读观察指标：

1. “日内位置”按 `(现价 - 日低) / (日高 - 日低) * 100` 计算并限制在 0 到 100；行情延迟、字段缺失或日高不大于日低时显示 `--`。
2. “振幅/ATR”按实时日高低差除以最近完成 15m K 线计算出的绝对 ATR14；行情延迟、ATR 样本不足或分母无效时显示 `--`。
3. 日内位置、振幅/ATR、盘口与其他实时字段只能作为观察证据，不得生成、清除、翻转或升级正式买卖信号。

## REQ-DOW-MONITOR-P0-FRESHNESS-001

趋势监控列表必须分别展示行情、盘口、1m K线和后端分析的数据年龄：

1. 年龄以页面当前时间减去各字段自身的源时间戳计算，最小为 0 秒。
2. 源时间缺失时显示 `--`。
3. 任一实时客户端延迟标记为真，或数据年龄超过 90 秒时，该字段必须显示为延迟/弱化状态。
4. 分字段新鲜度只说明证据时效，不得覆盖稳定决策字段或持久化正式信号。
