# A股涨跌停梯队盘中实时规范

规格 ID：`SPEC-LIMIT-LADDER-REALTIME-001`

权威依据：产品负责人于 2026-07-21 确认涨跌停梯队在 A股开市后接入当天实时数据。

## REQ-LIMIT-LADDER-REALTIME-001

未指定历史日期时，涨跌停梯队必须使用当前配置的实时行情源，以最近已落盘 enriched 日线作为前一交易日基线，按实时开盘、最高、最低和最新价计算当天涨停、炸板、跌停、翘板及连续涨跌停板数，并返回实时行情所属的 A股交易日期。

涨跌停价格必须复用系统统一的交易所半入规则和板块涨跌幅限制。缺失当天实时行情的证券不得沿用前一日涨跌停状态。实时源失败时允许回退最近已落盘日期，并明确返回非实时结果。

显式指定历史日期时，不得读取或混入实时行情。页面在实时模式下必须周期刷新；选择历史日期后停止周期刷新。

- 可执行测试验证显式历史日期不访问实时源。
