# 道氏选股执行反馈

## REQ-DOW-SCREENER-FEEDBACK-001

港股、美股或 A 股道氏选股请求成功后，页面必须显示可见的完成结果。若返回股票列表为空，页面必须明确显示对应市场“选股完成，当前暂无符合条件的股票”，不得呈现为无变化的空白区域。

## REQ-DOW-SCREENER-REALTIME-RUN-001

点击“执行选股”必须启动当前市场的全市场道氏多周期实时扫描任务，并轮询显示完成数量、总数和当前股票。扫描必须由上游实时任务读取本地 ClickHouse/WebStock 分钟数据计算，任务完成后才允许读取本次物化结果；不得以预计算榜单或缓存读取替代实时扫描。
