# 市场看板实时交易日期规范

规格 ID：`SPEC-MARKET-OVERVIEW-LIVE-DATE-001`

权威依据：产品负责人于 2026-07-21 确认 A股、港股开市并收到当天实时行情后，当天日期必须可选择。

## REQ-MARKET-OVERVIEW-LIVE-DATE-001

市场看板在未指定历史日期且成功取得实时行情时，必须按行情时间戳和对应市场时区返回实时交易日期。A股与港股使用亚洲时区，美股使用纽约时区。

日期选择器的最大日期必须取本地最新日线日期与实时交易日期中的较晚者。用户选择实时交易日期时，页面必须保持实时请求模式，不得将其作为已落盘历史日期请求。选择早于实时交易日期的日期时，必须继续使用历史日期请求。

## 验收

- 后端测试验证相同时间戳分别按 A股/港股与美股市场时区得到正确交易日期。
- 前端测试验证实时日期晚于日线日期时当天可选，且选择当天映射为实时模式。
- 前端测试验证历史日期仍作为显式历史请求保留。
