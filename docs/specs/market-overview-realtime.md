# 市场首页实时汇总规范

规格 ID：`SPEC-MARKET-OVERVIEW-REALTIME-001`

权威依据：产品负责人于 2026-07-20 确认将美股市场首页数据改为实时接入。

## REQ-MARKET-OVERVIEW-REALTIME-001

未选择历史日期时，市场首页必须以最近日线数据作为股票范围和技术指标基线，并用当前配置的实时行情源覆盖最新价、涨跌幅、成交量和成交额。实时源未直接提供涨跌幅时，必须使用最新价和昨收价计算；实时昨收缺失时，以覆盖前的最近日线收盘作为昨收基线。实时字段缺失时必须保留日线字段，不得将有效日线值覆盖为空。

涨跌家数、涨跌分布、市场成交额、领涨领跌及成交额排行必须基于覆盖后的数据重新聚合。

用户明确选择历史日期时，系统不得读取或混入实时行情。

## 验收

- 可执行测试以确定的日线基线和实时快照验证实时覆盖及聚合结果。
- 可执行测试验证缺失涨跌幅的补算语义。
- 可执行测试验证历史日期不会访问实时行情源。
