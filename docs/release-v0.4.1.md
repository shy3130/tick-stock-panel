# v0.4.1 版本说明

本页记录 v0.4.1 的变更及升级步骤。请从对应版本下载适用的安装包。[GitHub Releases](https://github.com/shy3130/tick-stock-panel/releases)

## 主要变化

- **看板和侧栏。** 桌面端可切换展开与图标模式。看板榜单、最高连板和梯队可直接打开个股，板块名称可打开成分股，涨跌停入口保留看板日期。指数页保留上证、深证、创业板和科创综指四只核心指数。[操作说明书](../操作说明书.md#5-通用界面与操作)
- **个股详情。** 可调整日 K 首屏范围、自定义信息条和管理指标公式。指标支持 JSON 导入导出，配置备份可带走信息条和指标偏好。[个股详情与图表指标](./custom-chart-indicators.md)
- **回测和引擎研究。** 工作台编排可独立安装的 Tivelo Data 与 Tivelo Backtest。普通策略回测默认前复权，支持后复权。日线仓位模拟在前复权下沿用复权价计算手数，在后复权下还原成交原价。Tivelo Pro 0.1.0a2 或更高版本启用和授权后，可在普通 A 股日线策略表单直接运行动态复权，自动读取本地行情和除权因子，按原价撮合。「引擎研究」可检查并运行已有归档和快照，跟踪阶段、查看报告和导出结果。[动态复权操作](./engine-platform/workbench-research-jobs.md#动态复权扩展) · [引擎研究](./engine-platform/workbench-research-jobs.md) · [回测证据](./backtest-evidence.md)
- **扩展与 AI。** 「设置 → 导入与备份」统一预检和导入资源、指标、扩展与引擎包。工作台登录会话和按 scope 授权的 Open API／MCP 提供各自的接入入口。[统一导入](./extension-packages.md) · [Pro 扩展安装、升级与卸载](./engine-platform/extensions-and-releases.md#安装和升级-tivelo-pro) · [AI 接入](./ai-integration.md)

## 升级与回滚

1. **升级前。** 在「设置 → 导入与备份」导出配置，停止旧实例后备份实际数据目录。保留旧安装包或镜像版本及原启动参数，以便回滚。Compose 和 Docker 用户先核对容器的 `DATA_DIR` 与宿主机挂载。[数据目录核对](./deployment.md#docker-升级前核对数据目录)
2. **升级。** 桌面版沿用原安装位置；Docker 重建时使用原数据挂载，源码部署按锁文件同步依赖。Docker 用户可固定到 `v0.4.1` 镜像标签，也可从对应源码构建。[桌面升级](./deployment.md#桌面版覆盖升级与旧配置恢复) · [部署步骤](./deployment.md)
3. **升级后。** 在「设置 → 关于」确认版本，可用「查看许可」核对工作台与 Tivelo 组件的许可。在「数据」页检查有效日期，再核对自选、策略、监控、数据源路由和已安装扩展。选一个已同步的短区间跑一次策略回测，对照价格口径和成交明细。
4. **回滚。** 先停新版并保留本次运行的数据。用旧程序或旧镜像读取升级前备份的副本，核对设置、行情和策略可用后再恢复运行。若只需要恢复桌面引擎组合，可按引擎回退说明保留当前工作台和数据目录。[引擎组合回退](./engine-platform/extensions-and-releases.md#回退与旧任务重放)
