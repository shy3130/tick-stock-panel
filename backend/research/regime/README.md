# Regime

当前市场状态标签、策略条件化和归因研究。

权威入口：

- `run_regime_ensemble.py`：8 配置 × 4 折及 2×2 归因。
- `diag_f4_regime.py`：F4 信号诊断。
- `run_market_structure_v1.py`：因果结构牛熊标签。
- `run_structure_strategy_replay_v1.py`：结构牛熊双腿历史复验。

`run_regime_conditional.py` 是保留的第一版可复现实验，不是最新结论。更早的宽度、
leader-index 和引擎门控脚本已移入 `research/legacy/regime/`。
